Put your own architecture diagrams in this folder, using these exact names:

  msc-thesis-architecture.png      -> Master's thesis card
  hybrid-ontology-architecture.png -> Hybrid ontology extraction card
  medontokg-architecture.png       -> MedOntoKG card

JPG or SVG also work: just change the file name in index.html
(search for "assets/architecture/").

Tips
- Crop to the diagram only (no page numbers or surrounding text).
- Export at least 1600 px wide so the labels stay readable.
- If a file is missing, the site automatically shows the simplified
  step-by-step diagram instead, so nothing looks broken.

You can delete this README once your images are in place.
